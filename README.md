# HERO-SNN
Code and Data for the HERO-SNN study. It includes 2 main folders:
1) Classification of EEG data to Recall 1 vs Recall 2 (Recall 1, corresponding to the first recall of the distressing memory at the beginning of the session, and Recall 2, corresponding to the second recall of the same memory following the distraction tasks).
2) Classification of sezuire vs no-seture using ECoG.
